模块说明

模块dsh-base
类型bundle
装配摘要所有 profile 的第一 patch 层（package.json dsh.bundle.patch=cordis.patch.yml），对空 profile 根做一次 insert ~80+ 行。装配行（按功能分组）：基础设施 timer/cordis-plugin-hmr/typert-registry/typert-loader/api-gateway；LLM llm/llm-deepseek/llm-pi-ai(dormant)/llm-retry；会话 session/session-persistence-jsonl/session-query-sqlite(openAt:never)/session-projection/session-title(+first-prompt-llm)/session-telemetry-otel(DISABLED)/session-checkpoint-policy/attachment-local/session-title；agent agent/agent-default-model(deepseek-v4-flash)/agent-loop(agents:[])/agent-instructions；权限 sandbox/sandbox-policy(workspace-write)/bash-sandbox(win32 disabled)/pwsh-sandbox(non-win32 disabled)/approval(ask)/permission-presets；shell shell-env/tool-bash(win32 disabled)/tool-pwsh(non-win32 disabled)/tool-jobs；fs fs-sandbox/tool-fs/tool-fs-search/fs-observation-policy/tool-str-replace-editor；上下文 skill/skill-filesystem/skill-badge(disabled)/tool-skill/commands/command-feedback/command-goal/command-compact/goal+goal-round-driver+tool-goal/plan-mode/token-meter/compaction-basic/tool-result-pruner/tool-todo/repeat-tool-reminder；子代理 subagent/subagent-spawn-in-process/subagent-fork-in-process/tool-subagent-control(+list-agents)/tool-subagent(+fork)/tool-subagent-report；workflow workflow-worker-thread/tool-workflow；spill spill-local/spill-policy；web web(deepseek-official)/web-search-deepseek/tool-web(fetch:false)；其余 subprocess-local/credentials-local/settings-file/user-questions/user-approval/tool-ralph/tool-call-timeout-policy/tools/system-prompt(persona '')。模式相关行（web persona/headless tools mode）不属于本层。
结构说明src/index.ts 无运行时 API（export {}，实质是 cordis.patch.yml）；package.json dsh.bundle.patch=cordis.patch.yml 由 profile composer 解析。patch 按行 id 寻址、整段替换 config、后写覆盖；行顺序无加载语义（服务可用性驱动）。base 是每个 profile 的第一层（DEFAULT_PROFILE_BUNDLES=[@deepseek-ai/dsh-base]，profile.ts:125），web/headless 模式 bundle 在其上叠加。
