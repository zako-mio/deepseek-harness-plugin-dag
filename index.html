方法说明

依赖判定三硬依据：E1 编译依赖（package.json peerDependencies / import）、E2 运行时依赖（ctx 服务注入 / ctx.get / 事件订阅）、E3 组合依赖（cordis.patch.yml 装配）。拓扑分层采用层次遍历：被依赖方先于依赖方（Layer 0 为基础能力，Layer 16 为最外层 UI 插件）。L2 另标注 22 个 web 变体 disabled 插件（模型侧工具移到 agent presets）。L3 追加 8 组（外部执行后端/协议与SDK/LSP集成/子代理外部后端/Web上下文扩展/会话存储变体/Hooks工具扩展/示例与框架）+ 4 特殊模块页（base/headless/app-boot/cmdline）。
